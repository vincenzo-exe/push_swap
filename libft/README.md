# Libft

This project has been created as part of the 42 curriculum by aahmamou

## Description

Libft is a C library containing functions that reproduce useful
standard C library functions, as well as additional string, memory,
conversion, output, and linked-list functions.

The goal of this project is to understand how these functions work
and to build a reusable library for future C projects.

## Instructions

Compile the library with:

```bash
make
```

Remove object files:

```bash
make clean
```

Remove object files and the library:

```bash
make fclean
```

Recompile everything:

```bash
make re
```

The compiled library is `libft.a`.
